How this dashboard works
The page sends your pasted TSV to GitHub Actions as Base64 through workflow_dispatch. The workflow writes it into data/input.tsv temporarily, runs the existing tracking bot, then updates data/results/latest.json/tsv/csv. This page reads latest.json and renders it as a table.
